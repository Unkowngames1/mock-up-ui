# Zhaalthur / mock-up-ui

An interactive browser-only OS mockup for GitHub Pages.

## Run

Open `index.html` locally or enable GitHub Pages for the repository root.

## Apps

- Zhaalthur Settings — `apps/settings.html`
- POM-2 File Explorer — `apps/file-explorer.html`
- Task Manager — `apps/task-manager.html`

## GitHub Pages

In **Repository Settings → Pages**, choose:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

All controls are simulated. The mockups do not access real files or change host-system settings.
